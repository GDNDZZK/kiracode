# 🚀 Kira Code

> Kira Code is based on the [legacy version of Kilo Code](https://github.com/Kilo-Org/kilocode-legacy). We forked from the classic version because we prefer the original design philosophy over the newer releases. It adds **Web Remote Control** capabilities on top of Kilo Code's powerful agentic engineering platform.

## ✨ Features

- ✨ **Code Generation** — Generate code from natural language descriptions
- ✅ **Self-Verification** — Automatically checks and validates its own work
- 🧪 **Terminal Commands** — Execute terminal commands directly from the agent
- 🌐 **Browser Automation** — Automate browser interactions for testing and web tasks
- ⚡ **Inline Autocomplete** — Get intelligent code completions as you type, powered by AI
- 🤖 **500+ AI Models** — Support for the latest AI models including GPT, Claude, Gemini, and more
- 🎁 **API Keys Optional** — Get started without configuring your own API keys
- 💡 **Credits System** — Use credits with 500+ models at transparent provider-matched pricing
- 🔧 **MCP Server Marketplace** — Easily find and use MCP servers to extend agent capabilities
- 🎯 **Multi-Mode** — Plan with Architect, Code with Coder, Debug with Debugger, and create custom modes

## 🌐 Web Remote Control (New)

Kira Code introduces **Web Remote Control**, a new feature that allows you to remotely control and monitor your AI coding agent through a web browser. This enables:

- **Remote Access** — Interact with your coding agent from any device with a web browser
- **Real-time Monitoring** — Watch the agent's progress and status in real time
- **Multi-device Workflow** — Start a task on your desktop and continue monitoring from your phone or tablet

## 🚀 Get Started

1. Install the Kira Code extension from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code).
2. Configure your AI provider or create an account to access 500+ AI models.
3. Start coding with AI that adapts to your workflow.

# 🚀 Kira Code

> Kira Code 基于 [Kilo Code 旧版本](https://github.com/Kilo-Org/kilocode-legacy)。我们从经典版本 fork，因为我们更偏爱原有的设计理念，而非新版本的改动。它在 Kilo Code 强大的智能工程平台基础上新增了 **Web 远程控制** 功能。

## ✨ 功能特性

- ✨ **代码生成** — 通过自然语言描述生成代码
- ✅ **自我验证** — 自动检查和验证自己的工作成果
- 🧪 **终端命令** — 直接从代理执行终端命令
- 🌐 **浏览器自动化** — 自动化浏览器交互，用于测试和 Web 任务
- ⚡ **内联自动补全** — 输入时获取由 AI 驱动的智能代码补全
- 🤖 **500+ AI 模型** — 支持最新的 AI 模型，包括 GPT、Claude、Gemini 等
- 🎁 **API 密钥可选** — 无需配置自己的 API 密钥即可开始使用
- 💡 **积分系统** — 使用积分访问 500+ 模型，价格透明，与提供商费率一致
- 🔧 **MCP 服务器市场** — 轻松查找和使用 MCP 服务器来扩展代理能力
- 🎯 **多模式** — 使用架构师模式进行规划，编码器模式进行编码，调试器模式进行调试，还可以创建自定义模式

## 🌐 Web 远程控制（新功能）

Kira Code 引入了 **Web 远程控制** 功能，这是一项新特性，允许你通过 Web 浏览器远程控制和监控 AI 编程代理。主要功能包括：

- **远程访问** — 从任何带有 Web 浏览器的设备与你的编程代理交互
- **实时监控** — 实时查看代理的进度和状态
- **多设备工作流** — 在桌面上启动任务，从手机或平板电脑上继续监控

## 🚀 快速开始

1. 从 [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) 安装 Kira Code 扩展。
2. 配置你的 AI 提供商或创建账户以访问 500+ AI 模型。
3. 开始使用适应你工作流的 AI 进行编码。
